# Wiki 轻量化实施记录

## 已实施

- 保留 Next.js、React、TypeScript 和 Tailwind，改为静态导出；移除 FastAPI、旧 API 客户端、API 环境变量和 `setup.py`。
- 首页及 5 篇文章在构建时生成正文 HTML；导航改为真实链接，支持独立路径、刷新与浏览器历史导航。
- Markdown 解析位于构建侧，标题 ID 和目录共用 AST 转换，包含全部标题并处理重复标题。
- 媒体同域提供；图片读取实际尺寸，懒加载、原生对话框放大；视频按需挂载地址，原生控件、无自动播放、不可见暂停。
- 删除 Three.js 和未使用的背景 Hook。移除旧毛玻璃滤镜与播放控件样式；保留深色双栏，手机端使用自然页面滚动。
- 新增开发媒体同步、静态预览、导出校验和内容测试；README 说明构建、缓存、发布与回滚。

## 构建产物比较

基线和优化版本均使用 Next.js 16.2.9 Webpack 生产构建。统计首页 HTML 引用的全部 JS/CSS 文件，去重后累加文件字节数及逐文件 gzip 字节数，包含旧浏览器 polyfill，不包含 HTML、媒体和网络协议开销。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 首页 JS/CSS 引用原始字节 | 717,043 | 548,864 |
| 上述文件逐文件 gzip 字节合计 | 217,940 | 168,861 |
| 本地 node_modules 磁盘占用 | 约 419 MB | 约 369 MB |
| 正文运行时 Wiki API 请求 | 先目录再正文 | 无 |
| 生产应用服务 | Next.js + FastAPI | 无，交给静态托管 |

JS/CSS 原始字节约减少 23.5%，gzip 合计约减少 22.5%。这不是浏览器实际传输量或加载速度测量，不能推断 LCP、内存或播放性能改善幅度。静态正文会增大 HTML，应在浏览器验收时一并测量。

## 已完成验证

- `npm test`：4 项内容与媒体同步测试通过，覆盖文章顺序、中文嵌套 slug、标题去重、代码围栏、缺失媒体、目录边界和过期文件清理。
- `npm run build`：生产静态导出、TypeScript 检查和导出验证通过。
- `verify-export`：首页及全部文章 HTML 包含标题与正文容器，目录锚点与构建解析结果一致；本地图片路径可解析且具有宽高；所有视频没有初始 src、没有 autoplay，保留原生控件和 `preload="none"`。
- 导出导航链接均对应实际 HTML 文件，存在 404 页面，页面不含旧 Wiki API 或 8002 地址。

## 待环境恢复后验证

当前环境禁止普通进程绑定本地预览端口，提权预览及浏览器启动请求被自动审批服务以 503 服务不可用错误拒绝。未能完成浏览器实测与桌面/手机截图；不将代码层面的预期行为当作已验证结果。

需要通过本地 `npm run preview` 补验：桌面/手机排版、无 JavaScript 阅读、导航与回退、章节锚点定位、图片放大与键盘关闭、视频拖动进度与全屏、滚出视口及后台暂停、无多视频自动下载，以及静态服务器 Range/404 响应。随后按同一设备和网络条件记录 FCP/LCP/CLS 与资源传输量。
