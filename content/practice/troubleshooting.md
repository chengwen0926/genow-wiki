# 常见问题与排查

## 找不到入口或模型

| 问题 | 先检查什么 | 后续处理 |
| --- | --- | --- |
| 看不到提示词生成或优化 | 个人设置中的控制台开关 | 开启后返回控制台 |
| 看不到置顶 | 置顶列表开关、是否已有置顶记录 | 从历史记录添加置顶 |
| 某模型不在列表或无法提交 | 图片／视频模式、模型及服务商是否启用 | 联系管理员检查模型状态 |
| 找不到视频延长或编辑 | 当前模型是否提供该模式 | 切换到支持该能力的可用模型 |
| 找不到模板分段拖动或默认设置 | 当前模板入口使用完整正文编辑 | 按[提示词与模板](/wiki/create/prompts/)操作，不沿用旧版入口 |
| 看不到管理后台 | 当前账号是否为管理员 | 需要平台管理权限时联系管理员 |

## 生成按钮不可用或上传失败

按以下顺序排查，避免反复提交：

1. 提示词是否为空，是否超过长度限制。
2. 参考文件是否仍在上传，是否显示错误。
3. 当前模式是否缺少必需的首帧、尾帧或其他输入。
4. 文件类型、数量、尺寸或时长是否符合当前模型提示。
5. 上一次请求是否还在准备或提交。
6. 账号、个人空间、模型及服务商是否可用。

上传失败后先处理对应素材，不要带着错误缩略图继续提交。素材过多时移除不需要的参考，再重新核对 `@` 标签。

![智能参考已有图片但提示词为空，生成按钮呈禁用状态](/media/tutorials/missing-required.jpg)

先补齐文字或当前模式要求的素材，再检查按钮状态。上传一张参考图不代表已满足全部必填条件。

## 任务一直等待或生成失败

| 现象 | 建议处理 |
| --- | --- |
| 长时间等待 | 先查看任务状态和错误信息，记录时间与模型后联系管理员；不要把等待直接等同于失败 |
| 网络断开后不确定是否已提交 | 重新打开历史查找本次任务，确认后再决定是否重试 |
| 提示个人密钥调用失败 | 检查服务商权限、余额及密钥状态，个人请求不会自动回退系统账号 |
| 多图任务只有部分成功 | 先保存可用结果，针对缺失或失败部分再调整 |
| 结果卡片在，但图片打不开 | 先使用媒体重新加载；任务可能已经成功 |
| 切换模型后报参数错误 | 重新选择当前模型支持的模式、比例、时长和参考数量 |
| 页面关闭后任务仍出现结果 | 离开页面不等于取消已提交的服务端任务 |

“再次生成”会创建新任务，可能再次使用服务商资源。状态不明确时先确认原任务，避免重复生成。

![控制台失败结果区域显示原因及复制报错信息入口](/media/tutorials/generation-failure.jpg)

记录错误后可重新编辑输入。截图中的“演示错误”来自独立数据，只用于说明错误位置，不代表服务实际故障。

## 结果与预期不符

将问题拆为主体、构图、风格和运动四类。主体错误时检查参考图与引用；构图错误时调整比例、主体位置与留白；风格错误时减少相互矛盾的描述；视频运动错误时先降低动作幅度，明确是否允许切镜。

例如“产品完整展示”与“杯口极近特写”可能冲突。先确定本次要做商品全貌还是细节特写，再保留与目标一致的描述。

## 素材找不到或无法删除

- **资产列表为空：** 检查来源、类型和收藏筛选，某组全部取消会显示为空。
- **上传素材不在库中：** 检查媒体分类及是否曾移除；误移除时联系管理员，生成结果与上传库不是同一集合。
- **历史预览仍可见但不能复用：** 原件可能已删除，预览仅用于说明历史输入。
- **画布图片不能单独删除：** 前往所属画布，删除对应节点及产物。
- **节点删除无权限：** 确认自己是否所有者，或是否为该团队节点的创建者。
- **项目显示删除处理中：** 等待处理；显示受阻时，先解决提示原因，再由所有者重试。
- **删除后容量没有全部下降：** 刷新空间统计；被历史引用的必要预览可能仍计入占用。

![资产页选中个人画布和收藏后显示暂无收藏内容](/media/tutorials/asset-filter-empty.jpg)

空列表可能来自来源与收藏筛选组合。逐项恢复正确来源、媒体类型和收藏状态后再判断是否真的缺少内容；本例仍有控制台素材。

## 无法协作分享或发布

| 问题 | 原因与处理 |
| --- | --- |
| 收到邀请但看不到项目 | 先明确接受邀请；已读不等于接受 |
| 只能看不能编辑 | 当前是仅阅读成员，请所有者调整角色 |
| 无法管理别人上传的项目素材 | 编辑者通常只能管理自己添加的条目，由所有者处理 |
| 分享搜不到用户 | 核对用户名、账号是否有效以及搜索输入是否足够明确 |
| 分享后对方不能编辑画布 | 内容分享只授予结果访问，协作需另发项目邀请 |
| 分享链接显示撤回或不可用 | 联系发送者确认状态，不能通过复制旧链接恢复权限 |
| 无法发布团队产物 | 由项目所有者发布，编辑者没有该权限 |
| 工作流导入超时 | 先更新画布检查是否已导入，再决定是否重试 |

## 提交有效的问题说明

将错误原文复制下来，并提供最少但足够定位的信息。不要附带密码、API Key 或不相关的私密素材。

```text
问题：视频生成失败
发生时间：今天 14:20 左右，注明所在时区
账号：填写用户名，不填写密码
入口：控制台 → 视频生成
模型与模式：填写界面显示的名称
参数：比例、分辨率、时长
输入：1 张首帧图，无视频和音频参考
操作：上传完成后点击生成
错误原文：粘贴完整报错
结果：历史中已有任务，但没有视频结果
补充：如可见，提供任务标识或经过遮挡的截图
```

通过团队指定渠道发给管理员。当前“问题反馈”按钮未完成实际投递，不应作为唯一反馈方式。
