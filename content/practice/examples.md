# 从需求到交付

本章项目和素材名称均为虚构，用于演示操作流程。模型、参数与额度以当前账号界面为准。

## 案例一 制作一组产品宣传图片

**目标：** 为晨光咖啡制作方形商品展示图和竖版宣传图。准备一张清晰的咖啡杯照片，杯子不要被遮挡。下方文件名用于说明素材组织方法，可以替换成自己的文件。

| 准备内容 | 示例 |
| --- | --- |
| 产品参考图 | `coffee-front.jpg` |
| 目标规格 | 方图 `1:1`、竖图 `9:16`，以模型支持为前提 |
| 需要保留的特征 | 白色杯身、圆形杯口、右侧杯柄 |
| 希望变化的内容 | 背景、桌面及画面留白 |

**第一步 建立基础描述。** 打开提示词生成，填写产品与场景描述，可选择写实风格；将内容保存为个人模板“咖啡商品图基础版”。

**第二步 生成方图。** 将文字发送到图片生成，添加产品参考图，在 `@` 菜单中选中它。将比例设为 `1:1`，选择可用数量后提交。

```text
以所选参考图中的白色咖啡杯为主体，保留杯口和右侧杯柄的形状。
咖啡杯放在浅色木桌上，杯子占据画面主要区域，主体完整。
背景为简洁的暖色咖啡馆，背景虚化，光线柔和。
不增加其他杯子，不添加文字、水印和新的标志。
```

**第三步 检查结果。** 放大查看杯柄是否完整、杯口是否自然、杯子是否重复。若主体太小，只调整“杯子占据画面主要区域”这一描述，再生成比较。若外形明显偏离，检查是否真正加入了参考图。

**第四步 制作竖图。** 对满意记录选择“重新编辑”，保持模型与参考图，比例改为 `9:16`，将构图要求改为“杯子位于画面下半部，上半部保留干净背景”。这一步重新生成竖版构图。

**第五步 整理交付。** 收藏满意结果，在生成资产页按控制台、图像和收藏筛选，批量下载。交付前解压核对方图与竖图数量，确认没有混入测试结果。

**预期成果：** 至少一张可用方图和一张可用竖图；各自的生成记录可追溯，模板可供下次复用。

![图片生成输入区已插入参考图引用标签](/media/tutorials/reference-tag.jpg)

对照第二步：先添加实际文件，再检查引用标签；文件名文字不能代替参考素材。

## 案例二 将静态产品图制作成短视频

**目标：** 将案例一的产品图变成一个平稳推进镜头。先下载选中图片，作为视频首帧准备；也可通过界面可用的素材选择方式直接引用。

1. 在控制台切换到视频生成，选择支持首帧图片的模型。
2. 选择图生视频或首帧模式，加入产品图。
3. 在模型允许范围内选择短时长；若有 5 秒选项，可以先用 5 秒。
4. 输入下方提示词，按交付目标选择横版或竖版比例。
5. 点击生成，等待结果后完整播放。
6. 若热气运动过强，只调整动作强度描述，再生成新版本。
7. 下载最终视频；需要封面时，播放至合适位置并截取当前帧。

```text
保持首帧中咖啡杯的外形、颜色和桌面位置。
镜头以很小的幅度缓慢推进，画面平稳连续。
杯口只有少量热气自然上升，背景保持静止。
不切换镜头，不增加人物，不改变杯子的数量。
```

**检查方法：** 分别观察开头、中间和结尾，重点看杯柄和杯口是否变形、背景是否突然跳动、镜头是否按要求连续推进。若需要同一产品的近景终点，可使用支持首尾帧的模型，再补充尾帧参考。

**预期成果：** 一段可播放、可下载的短视频，以及可选的一张视频封面。截帧保存到图像素材后，仍需主动选择才能用于下一次生成。

![视频首帧示意图与尾帧位置](/media/tutorials/video-frames.jpg)

对照第二、四步：首帧决定起始参考，提示词描述运动。需要封面时，按[截帧说明](/wiki/create/videos/#下载视频与截取画面)操作。

## 案例三 团队共同完成宣传内容

**目标：** 设计师与视频创作者共同制作，审核人员查看成果。需要三个已启用账号和一个团队项目。

| 角色 | 示例分工 | 项目权限 |
| --- | --- | --- |
| 项目负责人 | 创建项目、管理成员、发布最终作品 | 所有者 |
| 设计师 | 上传产品图，生成主视觉 | 编辑者 |
| 视频创作者 | 引用主视觉生成视频 | 编辑者 |
| 审核人员 | 查看结果并反馈 | 查看者 |

负责人也可以兼任设计师，按实际团队人数安排。

**第一阶段 准备项目。** 在团队项目页签新建“晨光咖啡宣传”，邀请成员并确认对方接受。随后设置角色，建立“产品原图”“场景参考”“最终成品”三个共享文件夹。

**第二阶段 制作主视觉。** 设计师上传产品图，在图像节点生成宣传图。选中满意结果，将当前产物加入共享素材，并移动到“最终成品”。

**第三阶段 制作视频。** 视频创作者选择共享主视觉作为视频参考，或连接对应上游节点；检查图片是否已经就绪，再填写动作和镜头描述并提交生成。

**第四阶段 审核修改。** 审核人员打开项目查看结果，通过团队约定的沟通渠道说明修改点，例如“结尾杯柄有轻微变化，请减小镜头运动幅度”。当前没有专门的画布评论批注流程，反馈时应明确素材版本和视频时间点。

**第五阶段 交付。** 负责人确认最终结果后下载成片。只给特定用户查看时使用内容分享；需要向平台展示且参考素材适合公开时，由项目所有者发布到 Playground。

**预期成果：** 项目保留输入、创作节点和结果；团队成员能按角色访问；交付对象与共享方式匹配。

[共享素材：移动与核对](/media/tutorials/shared-organize.mp4)

**文字步骤：** 核对素材与目标目录 → 拖入目录 → 进入目录核对。对照第二阶段，整理完成后再通知下游创作者使用，避免继续引用错误版本。
