# 用户、模型与用量

## 管理入口与职责

管理员登录后，从导航的用户菜单进入管理后台。侧栏包括 Dashboard、用户管理、模型管理、视频用量统计、提示词模板、存储管理和公告管理。

工作流模板维护位于管理员可见的“项目空间 → 工作流模板”，也有独立管理页面。管理员负责账号和平台配置；查看特定业务数据时使用对应的受控管理入口，不以平台身份替代普通项目成员权限。

## 创建与维护用户

**入口：** 管理后台 → 用户管理。

1. 点击“创建用户”。
2. 填写用户名、昵称和初始密码，组织为可选项。
3. 选择普通用户或管理员角色，确认创建。
4. 在用户列表核对账号，按团队约定方式交付账号信息。

创建时用户名需符合表单规则，密码至少 8 位。建议初始密码也满足大写字母、小写字母和数字组合，便于与用户修改密码的规则保持一致。

列表支持按用户名、昵称或组别搜索，并按组织分组展示。用户卡片提供以下操作：

| 操作 | 影响 |
| --- | --- |
| 信息修改 | 更新昵称、组织，或填写新密码；密码留空表示不修改 |
| 设为管理员或降为用户 | 改变平台管理权限 |
| 禁用或启用 | 改变账号是否可正常使用 |
| 删除用户 | 删除账号及其相关配额、模型权限和路由偏好设置；生成记录、画布等保留原始用户标识 |

组织字段用于分类展示，不会自动让同组织用户加入画布或获得素材访问权。删除用户也不是清理其全部业务文件的替代方法。临时限制使用时，可根据实际目的选择禁用。

![创建用户表单的用户名、昵称、组织、密码和角色](/media/tutorials/admin-user-create.jpg)

先核对身份信息与角色。截图停在提交前且密码为空，没有创建真实账号；账号交付按团队约定渠道完成。

## 调整个人存储容量

在用户信息修改窗口中，找到“个人存储容量（GB）”，填写有效非负数并点击“保存容量”。此项有独立保存按钮，不要只修改数字就关闭窗口。

容量按十进制 GB 展示。调低额度不会自动删除数据；启用容量限制后，已超额用户需要清理内容或获得更高额度，才能继续新增上传或生成。已经接受的任务可能仍然完成。

当前用户管理网页提供个人容量配置，没有完整的逐用户模型授权、生成配额和路由偏好编辑表单。遇到这些配置问题，应交由平台维护人员核对，不在用户卡片中寻找不存在的控件。

![用户信息修改中的个人存储容量与独立保存容量按钮](/media/tutorials/admin-user-storage.jpg)

容量输入右侧有独立“保存容量”按钮，与底部“保存修改”分开。图中 10 GB 为演示额度，没有修改真实账号。

## 查看 Dashboard

1. 选择“单日统计”或“时间段统计”。
2. 设置日期或使用快捷范围。
3. 选择控制台、个人画布、团队画布等统计来源。
4. 查看图片与视频的成功、失败、成功率及模型统计。
5. 从用户统计进入用户详情，核对对应范围的活动与生成信息。

至少选择一个统计来源。成功率按已完成和失败记录计算，仍在等待的任务不能直接算作失败。比较两组数据前，要保持时间范围与来源一致。

**示例：** 排查昨天团队视频失败偏多的问题，先选昨天和团队画布来源，找到相关用户和模型，再结合失败记录判断，避免把个人控制台数据混在一起。

![Dashboard 的来源、日期、成功率及用户和模型统计](/media/tutorials/admin-dashboard.jpg)

先检查右上方来源与日期，再比较成功率。全部数字为演示数据；进行中任务不算失败，也不计入成功率分母。

## 启用和停用模型

**入口：** 管理后台 → 模型管理。

1. 搜索模型或服务商名称。
2. 选择“按供应商分类”或“按模型分类”。
3. 根据需要筛选全部状态、可用或已停用。
4. 点击目标服务商下的模型卡片，切换该模型组的启用状态。
5. 等待操作完成并刷新，确认状态正确。

当前页面按服务商和模型组控制可用性。服务商本身已停用时，该模型卡片不能启用；需由平台维护人员先处理服务商状态。

停用会影响新的生成请求，用户即使保留旧模板或置顶配置，也可能不能再提交。它不表示已运行任务必然被立即取消。

当前网页没有服务商密钥编辑、逐接口参数编辑或“恢复默认配置”的完整操作入口。不要把模型管理卡片当作凭据管理工具；服务商配置与恢复由平台维护流程处理。

![按供应商分类查看模型启用状态](/media/tutorials/admin-models.jpg)

分类方式和状态筛选在顶部。确认服务商与模型后再切换卡片，避免停用错误线路。

### 调整同一模型的服务商顺序

切换“按模型分类”，在目标模型下使用服务商左侧的排序手柄调整调用顺序，等待保存完成后核对。此处调整同一模型的服务商优先级，不是编辑密钥或接口参数。

![按模型分类时服务商左侧显示调整调用顺序的手柄](/media/tutorials/admin-model-order.jpg)

示例 Seedream 4.5 下有两家服务商；图中只展示排序入口，没有更改生产路由。

## 视频用量统计

**入口：** 管理后台 → 视频用量统计。

设置起止日期后，左侧查看按模型汇总的生成次数，右侧查看用户在不同模型及分辨率下的累计视频时长。统计覆盖控制台和画布中成功或部分成功的相关视频记录。

有些历史记录没有可靠时长，页面会标记“时长未知”，不能把它当成 0 秒。视频生成时长与任务等待时间也不同：一个 5 秒视频可能需要较长时间完成生成。

此处是用量统计，不是服务商实际结算账单，不应直接将次数或秒数当作货币费用。

![模型生成次数与按用户、模型、分辨率汇总的视频时长](/media/tutorials/admin-video-usage.jpg)

示例共 2 次，720p 栏累计 10 秒。先核对日期和统计口径，再用于用量分析；这些演示数字不是账单。

## 存储统计与运行详情

**入口：** 管理后台 → 存储管理。

查看容量构成、用户存储排行，进入用户明细了解占用。按需展开“运行详情”，查看素材处理、文件转存、失败、引用缺口等状态。

统计按已登记文件和存储位置汇总，不扫描整个存储桶；不包含数据库、日志、备份和未登记临时文件。跨用户复用可能在各用户归属统计中重复体现，而平台总量会去重，因此不能简单相加用户排行得到服务器磁盘占用。

用户已删除内容与物理文件清理存在时间差，管理员可能仍看到保留文件。队列存在待处理项也不能单独证明 worker 正常运行。持续失败、待修复转存或引用缺口，应交由维护人员进一步检查。

![存储管理的容量构成、用户排行和用户内容恢复区域](/media/tutorials/admin-storage.jpg)

先选用户查看占用及当前可恢复内容。普通素材选择界面没有恢复入口；管理员应根据此处实际状态核对。

![存储运行详情中的处理队列、转存及引用核对状态](/media/tutorials/admin-storage-runtime.jpg)

点击右上角“运行详情”查看各类任务；队列数字不等于 worker 在线状态。示例统计为虚构数据。

## 检索用户内容与生成错误

管理员可进入站内路径 `/admin/content` 的“内容检索”页，搜索用户名或昵称，选择用户后查看其生成内容与错误记录。该页不在当前后台侧栏常驻导航中，可在平台域名后追加此路径访问。

排查时先确认账号、日期、入口和模型，找到对应错误后判断是输入不符、模型关闭、凭据失败还是服务异常。普通用户重新上传或反复提交，不一定能解决平台侧配置错误。

**示例：** 用户反馈某视频模型不可用，先核对模型管理中的服务商与模型状态，再检查该用户的错误记录和个人密钥情况。恢复正确条件后，由用户确认输入并重新提交。

![搜索演示用户后展开错误，显示模型、服务商、任务ID和提示词](/media/tutorials/admin-errors.jpg)

先选正确用户，再展开错误行。图中的“演示错误”用于说明定位位置，不能当成当前服务异常。
