# 公共模板与公告

## 管理系统提示词模板

**入口：** 管理后台 → 提示词模板。

1. 点击新建，填写模板名称与正文。
2. 保存模板。
3. 核对文字、长度及引用说明。
4. 点击启用，使普通用户能够在系统预设中使用。
5. 修改已有模板时，先保存内容，再根据需要调整启用状态。

新建系统模板默认停用。停用后不再供普通用户选择，但已有个人副本不会自动删除或更新。管理员在自己的个人控制台保存的模板仍属于个人内容，不会因为账号有管理员身份就自动变成系统预设。

当前管理页使用完整正文编辑，不提供独立系统分段库管理页签。不要按旧版分段管理说明操作。

**示例：** 创建“产品摄影基础描述”，正文以主体、场景、光线和限制四段组织，保存并检查后启用。当前编辑器不显示单独的用途说明输入框；如需说明适用场景，可在配套公告中写明，不要把不希望参与生成的管理备注混入正文。

## 创建与维护工作流模板

**入口：** 项目空间 → 管理员可见的“工作流模板”页签。

1. 新建工作流模板，填写名称并按需选择封面。
2. 进入模板画布，添加图像或视频节点、配置与连线。
3. 在卡片菜单的“编辑介绍”中写清用途、输入要求和运行顺序。
4. 观察编辑器右上角状态，等待“已保存”。
5. 回到自己的个人画布，导入模板并逐节点检查使用流程。

**当前模板编辑器使用自动保存。** 状态会显示待保存、保存中、已保存或保存失败；失败时点击“重试保存”。不要在保存失败或素材上传中关闭页面。保存后的内容会更新可导入模板，没有单独的草稿发布审批步骤，也不提供可供用户选择的历史版本。

模板的固定素材应使用可访问的普通图片、视频或音频。Vidu 主体、Kling 元素等账号绑定资源不应直接放入通用模板。需要用户自行提供的输入，在简介与节点名称中说明，例如“先上传产品图，再运行此节点”。

模板编辑不是用户成片交付；验证生成流程时，导入自己的普通画布进行测试，测试结果不会自动成为模板固定输入。

## 移除工作流模板与处理保存冲突

在模板卡片中执行删除或移除，会阻止后续导入，已经导入的用户副本不受影响。

当前项目空间的模板管理入口不提供“查看已移除模板”或“恢复模板”按钮，旧管理地址也会跳转到项目空间。误移除后需要恢复时，应联系平台维护人员核对处理，不要将旧版管理页步骤用于当前界面。个人或团队画布项目的删除也不能视为可恢复的模板移除。

多人维护同一模板时，如果出现内容已变化或保存冲突，先保留本地需要的文字，再重新加载确认最新内容，不连续覆盖其他人的修改。

## 创建与发布公告

**入口：** 管理后台 → 公告管理 → 右下角新建按钮。

1. 填写公告标题与正文。
2. 选择普通、成功、提醒或紧急级别。
3. 选择全部用户或指定用户；指定用户时搜索并勾选接收人。
4. 如需引导操作，选择可用的站内跳转页面。
5. 需要定时发布时设置日期和时间；立即发布时不要设置未来时间。
6. 选择保存草稿，或确认后点击“发布公告”。

指定接收人最多 500 位，正文最多 20000 字符。公告按纯文本展示，不应将 Markdown 标记当作一定会渲染的格式。

日期时间控件按浏览器本地时间输入和展示。跨时区操作时，发布前核对时间。保存草稿不会向普通用户发布；未来定时公告需要完成发布操作，随后按设定时间生效，发布后可在历史中核对状态。

## 公告历史与撤回

左侧公告历史可分页浏览，点击记录查看详情。草稿可编辑或发布；需要停止展示的公告可撤回。全体公告在有效期内对平台用户可见，也包括发布后新加入的用户。

撤回不能收回用户已经阅读或复制的文字。发现重要信息写错时，应根据当前状态撤回并发布正确内容，避免仅在私下说明而保留错误公告。

## 示例 发布模板上线通知

先建立并启用“产品摄影基础描述”，在用户侧确认系统预设可见，再创建公告：

```text
标题：产品摄影提示词模板已上线

正文：
控制台的提示词生成中已提供“产品摄影基础描述”。
打开模板菜单，切换到系统预设后选择。
使用前请替换产品描述，并添加自己的参考图。
该模板只填入提示词，不会自动提交生成任务。
```

若只向试用成员开放通知，选择指定用户；面向全平台时选择全部用户。公告发布与模板启用是两步操作，应分别确认。
