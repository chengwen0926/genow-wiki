# 快捷操作与功能边界

## 快捷操作

| 操作 | 使用位置 | 结果 |
| --- | --- | --- |
| Enter 或 Shift+Enter | 图片／视频提示词编辑器 | 换行，不提交生成 |
| 输入 `@` | 支持素材引用的提示词编辑器 | 打开素材选择菜单 |
| Esc | 支持关闭的菜单、弹窗和素材菜单 | 关闭当前浮层；处理中是否可关闭依界面状态 |
| Ctrl/Cmd+C 后 Ctrl/Cmd+V | 画布选中节点且焦点不在输入框 | 创建同类型空节点，不复制原内容 |
| Delete | 有编辑权限的画布 | 删除选中节点或连线，节点删除需确认 |
| Ctrl 加右键拖动 | 可编辑画布 | 切割经过的连线 |
| 截取当前帧 | 视频详情 | 下载截图或加入图像素材 |

![视频截帧预览中的下载到本地与添加到图像素材](/media/tutorials/frame-actions.jpg)

“截取当前帧”之后还要选择去向。加入素材库不会自动替换输入，需要返回生成面板重新选择。

## 当前常用界面的功能边界

| 功能 | 当前情况 | 应如何操作 |
| --- | --- | --- |
| 自助注册 | 未提供完整注册流程 | 向管理员申请账号 |
| 自己修改昵称 | 个人设置没有编辑入口 | 联系管理员 |
| 问题反馈提交 | 页面尚未接入实际投递 | 使用团队约定的联系渠道 |
| 个人密钥停用或删除 | 模型设置已提供启停及删除入口 | 核对服务商、状态与正在执行的任务后操作 |
| 模板默认设置和独立分段库 | 当前常用入口未开放 | 使用完整正文模板 |
| 个人模板删除 | 我的模板卡片操作菜单提供“删除个人模板” | 核对模板名称后按确认提示操作 |
| 个人素材条目恢复 | 当前常用素材选择界面未接入恢复入口 | 联系管理员核对，或重新上传原文件 |
| 工作流模板导入 | 从模板库拖到画布 | 不能按旧版“导入”按钮步骤寻找入口 |
| 已移除工作流模板恢复 | 当前项目空间未提供按钮 | 联系平台维护人员核对处理 |
| 独立保存未生成的配置 | 当前主要使用历史记录置顶 | 完成生成后置顶相应记录 |
| 完整复制画布节点配置 | 当前复制粘贴只创建空节点 | 使用工作流模板复用结构 |
| 工作流自动一键执行 | 未作为通用流程提供 | 逐节点检查并生成 |
| 分享收发记录与全文搜索 | 内容分享提供“收到的／已发送”；没有私信撰写与正文全文搜索 | 按收发分类打开记录核对 |
| 分享弹窗设置有效期 | 当前没有此输入项 | 按分享现有状态处理；当前弹窗不提供撤回回执入口 |
| Playground 标题与作品说明 | 当前没有输入项 | 发布单个结果及生成信息 |
| 用户删除后的业务内容清空 | 删除账号不会自动清空全部业务记录 | 按相应业务内容管理流程处理 |
