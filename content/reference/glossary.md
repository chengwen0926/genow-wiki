# 术语与参数

| 术语 | 含义 | 容易混淆的地方 |
| --- | --- | --- |
| 提示词 | 描述生成目标的文字 | 写文件名不等于上传文件 |
| 模型 | 执行图片或视频生成的 AI 能力 | 同一个模型可能有不同服务商线路 |
| 服务商 | 提供模型调用服务的平台 | 个人 Key 配置在服务商层面 |
| 参考素材 | 指导生成的图片、视频或音频 | 不一定会完整出现在结果中 |
| 首帧与尾帧 | 视频开始与结束画面的参考 | 两个槽位不能随意互换 |
| 主体或元素 | 服务商管理的可复用人物或物体资源 | 受账号凭据限制，不等于普通图片 |
| 生成任务 | 一次提交后的处理过程 | 一个任务可以产生多个文件 |
| 生成资产 | 生成所得图片或视频文件 | 与个人上传库的记录不同 |
| 画布节点 | 承载输入、参数和结果的创作单元 | 删除会影响节点下全部产物 |
| 工作流模板 | 可导入的节点与连线结构 | 导入不会自动执行生成 |
| 提示词模板 | 可复用的文字内容 | 不保存本次参考文件和生成参数 |
| 置顶 | 保存生成配置以供恢复 | 不是结果文件的备份 |
| 收藏 | 对结果或作品做个人标记 | 不复制文件，不改变公开范围 |

| 参数 | 先如何选择 | 何时调整 |
| --- | --- | --- |
| 比例 | 按最终横版、竖版或方形用途 | 主体被裁切或需要不同展示版式时 |
| 分辨率 | 先用模型默认或允许的较低规格验证 | 构图确认后按交付需要提高 |
| 图片数量 | 先从少量开始 | 需要比较多个构图时 |
| 视频时长 | 先选择可用短片段验证运动 | 运动稳定后再增加内容长度 |
| 智能时长 | 仅在支持的模型中选择 | 希望模型自行安排片段长度时 |
| 多镜头 | 根据是否需要切镜选择 | 单镜头与多镜头叙事需求变化时 |
| 参考素材数量 | 只放与目标直接相关的内容 | 需要补充不同视角或场景信息时 |
