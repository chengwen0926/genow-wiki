# 登录与个人设置

## 登录与修改密码

**入口：** 平台登录页。

1. 输入管理员提供的账号和密码。
2. 点击登录，进入平台后确认头像和账号信息属于自己。
3. 若需要修改密码，在登录页点击“修改密码”。
4. 填写账号、当前密码、新密码和确认新密码，提交修改。
5. 密码更新成功后，使用新密码登录。

修改密码要求新密码至少 8 位，并包含大写字母、小写字母和数字。此操作需要当前密码；忘记密码时联系管理员处理。当前自助注册页面未提供完整开户流程，新用户应先向管理员申请账号。

退出登录通过导航中的用户菜单完成。在公共设备上使用后，应退出自己的账号。

## 个人设置与颜色模式

**入口：** 点击导航头像 → 个人设置。

- 点击头像区域可以选择并上传新头像；上传失败时页面会显示错误。
- 查看当前昵称和用户名，避免在错误账号下进行创作。
- 使用颜色模式开关切换深色或浅色，登录页也提供颜色模式入口。
- 颜色偏好保存在当前浏览器；更换设备或浏览器时可能需要重新设置。

当前个人设置页展示昵称，但未开放昵称编辑按钮。需要修改昵称时，请联系管理员。

## 控制台功能开关

个人设置中的“控制台设置”影响功能入口是否显示。

![个人设置中的控制台设置，展示置顶列表、提示词生成和提示词优化三个开关](/media/tutorials/settings-panels.jpg)

图中三个开关均已开启，账号为虚构的“文档演示”。找不到对应入口时，先检查自己的开关状态，再返回控制台；无需重新生成或重新上传素材。

| 设置 | 开启后的用途 | 关闭后的影响 |
| --- | --- | --- |
| 置顶列表 | 在控制台查看并应用已置顶的生成信息 | 隐藏列表和置顶入口，已保存记录仍保留 |
| 提示词生成 | 增加提示词生成选项，组织描述、镜头、风格和灯光 | 控制台只显示图片与视频生成选项 |
| 提示词优化 | 在提示词生成中显示 AI 优化入口 | 隐藏优化入口 |

**示例：** 找不到“提示词生成”时，先到这里开启，再返回控制台切换到对应选项。

## 查看用量与个人空间

**入口：** 头像 → 用量统计。

1. 查看顶部“个人存储空间”的已用容量和上限。
2. 点击刷新获取最新空间信息。
3. 使用“今日”“近 7 天”“近 30 天”切换个人控制台统计范围。
4. 查看图片、视频及模型统计；这些统计按北京时间计算。
5. 需要清理内容时，点击“管理生成资产”。

**模型统计的口径**

- **次数**：包含已提交、进行中、成功和失败的所有任务。
- **成功率**：只按已结束的任务计算，进行中的任务不参与。

**示例：** 已有 1 次成功任务，又提交了 1 次仍在生成中的任务时，模型统计会显示“2 次，成功率 100%”。此时成功任务仍为 1 次，新增任务只是计入总次数，并未提前计为成功。

个人控制台用量与画布用量不是同一统计范围，不能用此处数字代表所有项目活动。空间计额也不等于存储服务器的物理占用：仍被历史记录使用的预览可能继续占用空间。

启用容量限制后，空间已满会阻止新的上传或生成。已经被接受的任务仍可能完成，所以容量偶尔可以超过上限。降低额度不会自动删除现有内容。

## 配置个人模型密钥

**入口：** 头像 → 模型设置。

API Key 是服务商提供的调用凭据。只有在需要使用自己服务商账号时才配置；平台已有可用系统线路时，可直接按平台安排使用。

1. 找到对应服务商，例如 Vidu、Kling、Volcengine 或 RunningHub。
2. 在该服务商的输入框粘贴 API Key。
3. 点击“应用”。
4. 看到“已保存并启用”后，检查状态提示。
5. 如需替换，输入新的 Key 并再次应用。

**保存成功仅说明配置已保存，实际可用性需要在服务商调用时验证。** 对符合模型和线路条件的请求，已启用的个人密钥优先使用；个人调用失败不会自动切换到系统账号。平台关闭的模型或服务商不能通过个人密钥绕过。

当前网页提供保存和替换入口，没有停用、删除密钥的操作按钮。需要撤销个人配置时联系管理员协助，不能通过清空输入框来删除已保存的 Key。不要在提示词、模板、私信或问题反馈中粘贴密钥。

Vidu 主体和 Kling 元素与创建时使用的服务商账号凭据有关。替换 Key 后，旧主体可能不再显示或可用，应在新配置下重新创建。尚未执行的任务也可能受凭据变化影响，建议先完成当前任务再调整。

## 接收私信与问题反馈

在个人设置中可开启或关闭“接收用户私信”。关闭后仍可收到系统通知、素材分享和团队邀请。

“问题反馈”页目前提供输入框，但“提交反馈”尚未接入实际提交流程。请使用团队约定的联系渠道或站内私信联系管理员；不要将点击该按钮视为已经送达。反馈内容的填写示例见[常见问题与排查](/wiki/practice/troubleshooting/)。
