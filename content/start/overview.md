# 认识 Genow

## 从哪个入口开始

| 入口 | 主要用途 | 适合的任务 |
| --- | --- | --- |
| 控制台 | 输入提示词、选择模型、提交图片或视频生成 | 快速验证创意，比较不同生成结果 |
| 项目空间 | 创建个人或团队画布，用节点组织创作 | 从产品图逐步制作主视觉和视频 |
| 生成资产 | 集中查找、预览、收藏和下载结果 | 找到过去生成的内容并整理交付 |
| Playground | 浏览、收藏和发布平台作品 | 查看其他作品的生成信息，展示成果 |
| 消息铃铛 | 查看通知、邀请、内容分享，发送私信 | 接受项目邀请，向其他用户传递内容 |
| 头像与个人设置 | 个人资料、界面偏好、用量和个人模型密钥 | 调整创作环境，查看空间占用 |
| 管理后台 | 用户、模型、统计、系统模板与公告管理 | 仅平台管理员使用 |

第一次使用建议从控制台开始。需要把多个生成步骤保存在同一工作环境中时，再使用项目空间。

## 先理解几个概念

**提示词**是你对目标画面的文字描述。**模型**是执行生成的 AI 能力，不同模型支持的输入、比例和时长不同。**参考素材**是用来指导生成的图片、视频或音频。

点击生成后会创建一个**生成任务**。任务完成后，得到一张或多张图片，或者一个视频；这些文件称为**生成资产**。同一任务可能包含多个产物，因此“删除一张图片”和“删除整条任务记录”影响范围不同。

**项目空间中的一个项目对应一张画布**。画布中的图像节点、视频节点承载输入、参数和生成结果；连线用于建立上下游参考关系。当前不要将项目理解为包含多张子画布的文件夹。

## 不同角色怎么阅读

| 你的身份 | 推荐阅读顺序 |
| --- | --- |
| 首次使用者 | [登录与个人设置](/wiki/start/account/)、[生成第一张图片](/wiki/start/first-image/)，再阅读[控制台图片生成](/wiki/create/images/)、[生成资产与个人素材](/wiki/create/assets/) |
| 图片创作者 | [控制台图片生成](/wiki/create/images/)、[提示词与模板](/wiki/create/prompts/)、[生成资产与个人素材](/wiki/create/assets/)及[案例一](/wiki/practice/examples/#案例一-制作一组产品宣传图片) |
| 视频创作者 | [控制台视频生成](/wiki/create/videos/)、[项目空间与画布](/wiki/create/canvas/)及[案例二](/wiki/practice/examples/#案例二-将静态产品图制作成短视频) |
| 团队成员或项目负责人 | [项目空间与画布](/wiki/create/canvas/)、[工作流模板](/wiki/create/workflows/)、[团队协作与共享素材](/wiki/collaborate/teams/)、[Playground 作品发布](/wiki/collaborate/playground/)、[消息通知与素材分享](/wiki/collaborate/messages/)及[案例三](/wiki/practice/examples/#案例三-团队共同完成宣传内容) |
| 平台管理员 | 先了解用户流程，再阅读[用户、模型与用量](/wiki/admin/platform/)、[公共模板与公告](/wiki/admin/content/) |

平台管理员与项目所有者是两种身份：管理员负责平台管理，项目所有者负责具体画布。成为平台管理员并不等于自动拥有所有个人画布的编辑权限。

## 贯穿手册的示例

假设你要为“晨光咖啡”制作宣传内容：先在控制台生成产品图片，再把选中的图片作为视频首帧；需要多人配合时创建团队项目，将素材加入项目库；最终下载成片，或向指定用户分享，或发布到 Playground。

这三个交付方式具有不同的可见范围，详见[权限与共享范围](/wiki/reference/permissions/)。
