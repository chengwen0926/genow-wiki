# 消息通知与素材分享

## 查看消息

**入口：** 导航或画布中的消息铃铛。

当前消息窗口包含“消息通知”和“内容分享”分类，并提供“写消息”入口。未读标记帮助识别新内容；可切换“仅看未读”、手动刷新和加载更多。

消息通知包含公告、私信、画布邀请和成员变更等。长正文可展开阅读；按卡片提供的操作标为已读、回复或处理邀请。

标为已读只改变阅读状态，不等于接受邀请，也不等于撤回分享。邀请要明确点击接受或拒绝。

## 发送与回复私信

1. 点击“写消息”。
2. 输入至少两个字符搜索用户名或昵称。
3. 从候选结果选择接收人，核对账号。
4. 输入正文，点击“发送”。
5. 看到“消息已发送”提示后再离开。

一次最多选择 50 位接收人，正文最多 4000 字符。回复已有消息时，通过该消息的回复操作进入；若无法回复，检查页面提示和对方接收状态。

当前写消息页提供发送和回复，不提供完整的已发送列表或历史全文搜索入口。搜索框用于选择收件人，不是搜索消息正文。

## 分享生成素材

**入口：** 打开素材详情 → “分享给用户”。

1. 确认素材已经保存且可以正常预览。
2. 在分享弹窗中搜索用户名或昵称，核对候选人的账号。
3. 点击候选人，让其进入输入框内的已选标签。
4. 检查“已选”人数和接收人列表，再点击右侧勾选按钮“发送分享”。
5. 等待出现“已分享，对方可在消息中心查看素材和生成信息。”，再关闭窗口。
6. 接收人进入消息窗口的“内容分享”，点击查看分享。

![素材分享弹窗输入演示后出现演示审核员候选项，同时显示账号demo_reviewer](/media/tutorials/share-search.jpg)

**先搜索，再选择。** 搜索框中输入名字不代表已经选中；点击候选项后，接收人才会进入已选列表。截图使用独立演示场景和虚构账号，不向真实用户发送消息。

![分享弹窗已选中一位演示审核员，展开说明提示分享结果和参数不会授予画布或参考文件访问权限](/media/tutorials/share-ready.jpg)

**发送前核对两件事：** 接收人已显示为框内标签，“已选”人数正确。可点击标题旁的说明图标查看分享范围；误选时移除对应标签，或点击“清空”重新选择。图中是发送前状态，不表示已经发送成功。

当前可选择其他有效站内用户，不要求接收人已经加入素材来源项目。分享者仍须具有素材分享权限：自己的个人素材，或自己作为所有者／编辑者参与的有效团队项目素材。

一次分享最多选择 50 人。接收人可以查看这次分享的结果及生成参数快照，**不会因此获得源画布权限或参考文件的访问权**。当前简化分享弹窗没有留言输入框，需要说明审核要求时另发私信。

## 分享入口与不可用状态

当前分享弹窗提供接收人选择和发送成功提示，没有“查看或撤回这次分享”的回执入口，也没有有效期设置控件。不要按旧版操作说明寻找这些按钮。

已有消息可能显示“已撤回”“已到期”或不可用状态，源内容或源项目不可用也可能使分享无法打开。按界面提示处理，必要时联系分享者或管理员核对。已读状态不能证明素材以后永远可访问，也不能收回对方已经下载的文件。

## 选择正确的沟通方式

| 需求 | 使用方式 | 对方获得什么 |
| --- | --- | --- |
| 告诉同事需要改什么 | 私信 | 文字信息 |
| 让指定用户看一份结果 | 内容分享 | 被分享结果与允许展示的生成参数 |
| 让团队继续使用一份素材 | 项目共享素材 | 按项目成员权限查看或用于创作 |
| 让成员共同编辑工作流程 | 项目邀请并授予编辑权限 | 团队画布编辑能力 |
| 向平台展示作品 | Playground 发布 | 作品、生成信息及发布时开放的参考素材 |

## 示例 发送成片供审核

打开咖啡视频详情，点击“分享给用户”，选择审核人员并确认发送成功。再通过私信补充“请确认 2 秒附近杯柄是否变形，以及结尾是否适合加字幕”。审核人员在“内容分享”中查看视频，无需编辑画布，再通过私信回复意见。
