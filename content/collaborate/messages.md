# 消息通知与素材分享

## 查看消息

**入口：** 导航或画布中的消息铃铛。

当前消息窗口包含“消息通知”和“内容分享”分类，并提供“写消息”入口。未读标记帮助识别新内容；可切换“仅看未读”、手动刷新和加载更多。

消息通知包含公告、私信、画布邀请和成员变更等。长正文可展开阅读；按卡片提供的操作标为已读、回复或处理邀请。

标为已读只改变阅读状态，不等于接受邀请，也不等于撤回分享。邀请要明确点击接受或拒绝。

## 发送与回复私信

1. 点击“写消息”。
2. 输入至少两个字符搜索用户名或昵称。
3. 从候选结果选择接收人，核对账号。
4. 输入正文，点击“发送”。
5. 看到“消息已发送”提示后再离开。

一次最多选择 50 位接收人，正文最多 4000 字符。回复已有消息时，通过该消息的回复操作进入；若无法回复，检查页面提示和对方接收状态。

当前写消息页提供发送和回复，不提供完整的已发送列表或历史全文搜索入口。搜索框用于选择收件人，不是搜索消息正文。

## 分享生成素材

**入口：** 打开素材详情 → “分享给用户”。

1. 确认素材已经保存且可以正常预览。
2. 搜索并选择接收人。
3. 可填写分享留言，例如“请检查杯身外形和结尾画面”。
4. 点击“发送分享”。
5. 成功后通过“查看或撤回这次分享”打开回执详情。
6. 接收人进入消息窗口的“内容分享”，点击查看分享。

当前可选择其他有效站内用户，不要求接收人已经加入素材来源项目。分享者仍须具有素材分享权限：自己的个人素材，或自己作为所有者／编辑者参与的有效团队项目素材。

一次分享最多选择 50 人，留言最多 1000 字符。接收人可以查看这次分享的结果及生成参数快照，**不会因此获得源画布权限或参考文件的访问权**。

## 撤回与不可用状态

发送者在分享详情中可以撤回，撤回后不再允许正常访问该次分享。已到期、源内容不可用或源项目删除，也可能使分享无法打开。

当前分享弹窗没有有效期设置控件；遇到已有分享显示到期时，按状态提示处理。已读状态不能证明素材以后永远可访问，撤回也无法收回对方已经下载的文件。

## 选择正确的沟通方式

| 需求 | 使用方式 | 对方获得什么 |
| --- | --- | --- |
| 告诉同事需要改什么 | 私信 | 文字信息 |
| 让指定用户看一份结果 | 内容分享 | 被分享结果与允许展示的生成参数 |
| 让团队继续使用一份素材 | 项目共享素材 | 按项目成员权限查看或用于创作 |
| 让成员共同编辑工作流程 | 项目邀请并授予编辑权限 | 团队画布编辑能力 |
| 向平台展示作品 | Playground 发布 | 作品、生成信息及发布时开放的参考素材 |

## 示例 发送成片供审核

打开咖啡视频详情，点击“分享给用户”，选择审核人员并写明“请确认 2 秒附近杯柄是否变形，以及结尾是否适合加字幕”。发送后记录分享回执链接。审核人员无需编辑画布即可查看被分享的视频，再通过私信回复意见。
