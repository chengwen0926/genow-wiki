# 消息通知与素材分享

## 查看消息

**入口：** 导航或画布中的消息铃铛。

当前消息窗口包含“通知”和“内容分享”分类。通知可切换“仅看未读”并手动刷新；卡片中按需处理公告、画布邀请和成员变更。

标为已读只改变阅读状态，不等于接受邀请，也不等于撤回分享。收到邀请后，核对项目与邀请者，再选择“接受邀请”或“拒绝邀请”。

![通知卡片中的接受邀请、拒绝邀请和标为已读按钮](/media/tutorials/notifications-invite.jpg)

先核对邀请者和项目。接受、拒绝与已读是不同操作，图中没有处理真实邀请。

## 查看分享收发记录

1. 在消息窗口选择“内容分享”。
2. “收到的”显示别人发给你的分享；“已发送”用于核对自己发出的分享记录。
3. 点击卡片上的“查看分享”，检查结果与可展示的生成信息。
4. 若内容不可用，记录页面提示，联系分享者核对来源。

当前窗口不提供“写消息”、自由文本私信或历史正文全文搜索入口。需要讨论修改要求时，使用团队约定的沟通渠道；不要将分享记录当作聊天会话。

![内容分享中的收到的与已发送分类及查看分享按钮](/media/tutorials/notifications-sent.jpg)

切换“已发送”核对分享记录，再点击“查看分享”检查内容。示例记录由隔离环境提供，没有向真实账号发送。

## 分享生成素材

**入口：** 打开素材详情 → “分享给用户”。

1. 确认素材已经保存且可以正常预览。
2. 在分享弹窗中搜索用户名或昵称，核对候选人的账号。
3. 点击候选人，让其进入输入框内的已选标签。
4. 检查“已选”人数和接收人列表，再点击右侧勾选按钮“发送分享”。
5. 等待出现“已分享，对方可在消息中心查看素材和生成信息。”，再关闭窗口。
6. 接收人进入消息窗口的“内容分享”，点击查看分享。

![素材分享弹窗输入演示后出现演示审核员候选项，同时显示账号demo_reviewer](/media/tutorials/share-search.jpg)

**先搜索，再选择。** 搜索框中输入名字不代表已经选中；点击候选项后，接收人才会进入已选列表。截图使用独立演示场景和虚构账号，不向真实用户发送消息。

![分享弹窗已选中一位演示审核员，展开说明提示分享结果和参数不会授予画布或参考文件访问权限](/media/tutorials/share-ready.jpg)

**发送前核对两件事：** 接收人已显示为框内标签，“已选”人数正确。可点击标题旁的说明图标查看分享范围；误选时移除对应标签，或点击“清空”重新选择。图中是发送前状态，不表示已经发送成功。

当前可选择其他有效站内用户，不要求接收人已经加入素材来源项目。分享者仍须具有素材分享权限：自己的个人素材，或自己作为所有者／编辑者参与的有效团队项目素材。

一次分享最多选择 50 人。接收人可以查看这次分享的结果及生成参数快照，**不会因此获得源画布权限或参考文件的访问权**。当前简化分享弹窗没有留言输入框，需要说明审核要求时使用团队约定的沟通渠道。

![接收方查看分享结果及提示词、模型和参数](/media/tutorials/share-received.jpg)

接收人从“收到的”打开分享后，可核对结果与生成信息快照。能看到分享结果，不代表取得源画布编辑权。

## 分享入口与不可用状态

当前分享弹窗提供接收人选择和发送成功提示，没有“撤回这次分享”的回执入口；已发送记录在消息中心的“内容分享 → 已发送”查看，也没有有效期设置控件。不要按旧版操作说明寻找这些按钮。

已有消息可能显示“已撤回”“已到期”或不可用状态，源内容或源项目不可用也可能使分享无法打开。按界面提示处理，必要时联系分享者或管理员核对。已读状态不能证明素材以后永远可访问，也不能收回对方已经下载的文件。

## 选择正确的沟通方式

| 需求 | 使用方式 | 对方获得什么 |
| --- | --- | --- |
| 告诉同事需要改什么 | 团队约定的沟通渠道 | 修改要求与反馈 |
| 让指定用户看一份结果 | 内容分享 | 被分享结果与允许展示的生成参数 |
| 让团队继续使用一份素材 | 项目共享素材 | 按项目成员权限查看或用于创作 |
| 让成员共同编辑工作流程 | 项目邀请并授予编辑权限 | 团队画布编辑能力 |
| 向平台展示作品 | Playground 发布 | 作品、生成信息及发布时开放的参考素材 |

## 示例 发送成片供审核

打开咖啡视频详情，点击“分享给用户”，选择审核人员并确认发送成功。再通过团队约定的沟通渠道补充“请确认 2 秒附近杯柄是否变形，以及结尾是否适合加字幕”。审核人员在“内容分享”中查看视频，无需编辑画布，再通过约定渠道回复意见。
