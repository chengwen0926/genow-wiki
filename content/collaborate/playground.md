# Playground 作品发布

## 浏览作品

**入口：** 顶部导航 → Playground。

- “发现作品”：浏览平台已发布作品。
- “我的发布”：管理自己发布的作品和可见的撤销记录。
- “我的收藏”：查找自己收藏的作品。

选择上述分类后，点击卡片查看完整媒体和生成信息；当前列表没有单独的图像／视频筛选按钮。参考素材是否可见取决于作品的开放状态；历史作品可能未开放参考资料。

Playground 面向登录的平台用户，不是无需登录的互联网作品网站。作品收藏也不会授予源画布的编辑权限。

![Playground 的发现作品、我的发布和我的收藏分类](/media/tutorials/playground-browse.jpg)

先按用途切换分类，再打开作品卡片。这里只有一张虚构示例作品，避免混入无关内容。

![作品详情展示参考素材、提示词、模型与生成参数](/media/tutorials/playground-details.jpg)

右侧核对生成信息和已开放的参考图。示例为隔离数据，不是本次真实发布；自己作品的撤销入口位于详情下方。

## 发布自己的作品

1. 在 Playground 打开发布入口，或使用控制台结果卡片的发布入口。
2. 从可发布结果中选择一个资产。
3. 检查卡片预览，并按下方说明核对将向平台用户开放的内容。
4. 点击“上传到 Playground”旁的对勾（“确认上传”）完成发布。
5. 到“我的发布”中查看，并打开详情核对展示内容。

当前作品以单个生成资产为单位，没有作品标题、说明或标签输入框。多图任务中的每一张可发布图片是独立资产，不会自动成为一篇多图文章。

**发布会向平台用户开放结果、提示词、生成参数，以及本次使用的参考图片、视频、音频和主体预览。** 确认前检查这些参考资料是否适合公开。发布不会公开个人 API Key，也不会授予整个项目的访问权限。

![上传到 Playground 的确认界面展示单张作品卡片，下方对勾用于确认上传，叉号用于关闭](/media/tutorials/playground-preview.jpg)

预览卡片显示作品、作者与模型；下方对勾是“确认上传”，叉号是关闭。**当前弹窗没有单独的公开范围选择器，也没有标题、说明或标签字段。** 在进入此窗口前，应检查结果和参考素材是否适合向平台用户开放。

图中咖啡杯为示意素材，只展示发布前状态，没有创建真实作品。若只想给指定同事查看，可改用[站内素材分享](/wiki/collaborate/messages/)。

## 哪些结果可以发布

控制台结果需要属于当前用户，资产已就绪，并满足任务完成或部分成功等条件。画布结果需要当前用户是项目所有者，且项目、任务和产物仍然有效。

团队编辑者即使亲自提交过生成，也不能代替项目所有者发布项目作品。候选列表不出现某个结果时，应先检查这些条件。

## 撤销与重新发布

在自己的作品详情中点击“撤销发布”，作品停止在公开作品列表展示。源内容仍然有效时，可从自己的记录重新发布；同一资产再次发布会复用已有作品，不创建重复作品条目。

删除源资产、源任务或源项目可能使作品撤销且不能重新发布。撤销发布也不能收回其他用户已经下载的文件。

## 示例 展示一张咖啡主视觉

选择一张已完成的咖啡产品图，检查所用参考图可以向平台用户开放后发布。发布后到“我的发布”打开作品，确认图片、提示词和参考素材展示正确。如果只是想让一位同事审核，使用[消息通知与素材分享](/wiki/collaborate/messages/)的内容分享即可。
