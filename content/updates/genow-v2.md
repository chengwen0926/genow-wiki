# Genow v2 版本更新指南

本章面向使用过旧版 Genow 的用户，说明 **genow_v2 相较于旧版新增了什么、哪些操作发生了变化，以及升级后如何继续工作**。

对照范围：以 v2 合入前保留的 Genow 版本为旧版，核对截至 **2026-10-26** 的 v2 实现。当前 Genow 主分支已经合入 v2，因此两个项目目录名称不同，不代表它们仍是两个功能版本。这里记录的是功能演进，而不是目录差异；你实际能使用的模型和入口仍取决于服务器版本、账号权限与管理员配置。

## 先看主要变化

| 模块 | 旧版 Genow | Genow v2 的更新 | 类型 |
| --- | --- | --- | --- |
| 控制台 | 图片／视频生成、参考素材、生成历史与重新编辑 | 增加提示词生成面板、模板、历史配置置顶及界面开关 | 新增工具 |
| 项目空间 | 个人画布、图像／视频节点与连线 | 增加团队项目、成员权限与项目共享素材 | 新增协作 |
| 画布复用 | 手动创建和连接节点 | 从工作流模板库拖入预设节点、配置及连线 | 新增复用方式 |
| 图片修改说明 | 通过提示词和参考图表达修改要求 | 在图片上涂抹标记，保存为独立节点后供后续生成引用 | 新增标记工具 |
| 资产查找 | 浏览图像／视频结果，批量下载和删除 | 增加来源组合筛选、收藏与更明确的删除范围 | 已有功能增强 |
| 成果交付 | 主要通过下载结果交付 | 增加定向内容分享和 Playground 作品发布 | 新增交付方式 |
| 消息 | 没有当前的通知与分享中心 | 通过铃铛处理邀请、通知，查看收到的／已发送分享 | 新增消息入口 |
| 个人模型密钥 | 模型设置中有输入界面，未接入当前的保存与调用流程 | 可保存、替换、启用、停用和删除个人服务商密钥 | 从界面到可用功能 |
| 视频草稿 | 有独立“草稿模式”页面，面向多轮图像创作 | 独立旧页面已移除；Seedance 2.5 提供视频草稿与后续超分流程 | 入口变化及新增流程 |
| 管理后台 | Dashboard、用户管理、Seedance 用量统计 | 扩展模型与服务商排序、视频用量、容量与存储管理、模板及公告 | 管理能力扩展 |

**这些并非 v2 首次提供：** 图片／视频生成、智能比例、首尾帧与部分多模态参考、Vidu／Kling 主体相关入口、图像／视频节点、连线、节点复制粘贴、批量下载，旧版已存在相应实现。v2 的重点是把创作复用、协作、分享及管理流程补齐，不应把模型名称或全部旧能力都列成新功能。

## 控制台：减少重复输入和配置

### 提示词生成与模板

v2 增加独立的提示词生成流程：先描述主体，再选择焦段、镜头、光圈、景别、风格和灯光，把文字发送到图片或视频生成面板。系统预设和个人模板用于保存、复用完整正文。

提示词优化会先展示结果，再由你确认、重新生成或取消。**发送文字或确认优化，不会立即启动图片／视频生成。** 找不到相关入口时，到个人设置检查“提示词生成”和“提示词优化”开关。

**例子：** 为咖啡杯建立“产品摄影”模板，第一次使用木桌与暖光，第二次只把场景改为米白摄影棚。参考图仍需在本次生成中重新核对，文字模板不会打包上传文件。

详见[提示词与模板](/wiki/create/prompts/)。

### 置顶生成信息

从控制台历史记录置顶一组有效配置，之后在左侧置顶列表中回填提示词、模型、参数及参考内容。当前主要入口在历史记录上，不要在输入区寻找“置顶当前配置”按钮。

**例子：** 某次产品图的构图和比例合适，置顶该记录。下次点击“添加到控制台”，更换产品参考图并检查参数后再生成。回填会替换当前输入配置，但不会自行提交任务。

![置顶列表中的生成信息可回填到控制台](/media/tutorials/console-pin.jpg)

这类配置复用适合重复进行单次生成；需要复用整组节点与连线时，使用下文的工作流模板。详见[置顶常用生成配置](/wiki/create/images/#置顶常用生成配置)。

## 项目空间：从个人画布到团队创作

### 团队项目、成员与共享素材

旧版已经可以创建画布和连接图像／视频节点。v2 在此基础上增加个人项目与团队项目的区分，以及所有者、可编辑、仅阅读等成员权限。

团队项目可以邀请成员，并在项目共享素材库中建立文件夹、加入素材和整理目录。**个人上传素材与项目共享素材的可见范围不同**；把素材加入团队项目之前，先核对项目和成员。

**例子：** 在团队项目“晨光咖啡宣传”中，负责人邀请设计师为可编辑成员，邀请审核人为仅阅读成员；产品图统一放进“产品原图”文件夹，成员从同一个项目库取用。

旧个人项目不会因为升级自动变成团队项目，也没有常用的一键转换入口。需要多人编辑时，从团队项目页签新建。具体步骤见[团队协作与共享素材](/wiki/collaborate/teams/)。

### 工作流模板复用整组结构

v2 可以从画布左侧的工作流模板库，**将模板拖入画布**，一次获得预先组织的节点、输入配置与连线。管理员负责制作和维护模板。

导入的内容是独立副本，不复制模板的生成结果；模板之后修改，也不会同步改写已导入的画布。连线表示参考关系，导入后仍需逐节点检查并生成。

**例子：** 导入“产品图 → 场景图 → 视频”的模板，更换第一步参考图，检查后续输入，再按顺序生成。它比复制粘贴空节点更适合复用完整流程。

![从工作流模板库选择并拖入画布](/media/tutorials/workflow-library.jpg)

模板卡片用于选择流程；拖入后核对节点和连线，再填入自己的内容。完整短片见[工作流模板](/wiki/create/workflows/)。

### 涂抹标记表达修改位置

选中已有图片结果的节点，打开“涂抹标记”，用画笔、圆形、矩形或箭头标出调整位置，再“保存为新节点”。原图保留，标记图成为独立节点。

**保存只保存图片标记，不调用模型，也不是自动局部重绘。** 后续需连接到生成节点，在提示词中说明修改内容和去除标记的要求。

**例子：** 圈出杯身，保存标记图；将原图和标记图作为参考，输入“将蓝圈内杯身改为哑光青绿色，保留杯形与光影，去除蓝色标记”。核对后才提交生成。标记不是保证区域外像素不变的蒙版。

详见[涂抹标记及分步短片](/wiki/create/canvas/#涂抹标记)。

## 资产与交付：查找、分享和发布分开处理

### 来源筛选与收藏

生成资产页按控制台、个人画布、团队画布区分来源，并可组合选择图片／视频及收藏条件。批量下载在旧版已经存在，v2 的变化主要在查找、收藏与内容范围管理。

**例子：** 想找团队宣传片，选择“团队画布”和“视频”；如果列表为空，先核对来源和类型是否都至少选了一项。全部取消某组筛选会得到空列表，不代表显示全部。

删除时也要区分对象：资产页可处理选中的控制台产物，画布产物需回到所属画布删除节点。删除节点会涉及它的全部生成产物，不能当作只删除当前展示的一张图。详见[生成资产与个人素材](/wiki/create/assets/)。

### 定向分享、作品发布与通知

v2 增加两条交付路径：

| 目的 | 使用入口 | 可见范围与操作重点 |
| --- | --- | --- |
| 把结果交给指定用户 | 内容分享 | 选择接收方并核对内容；在消息中心查看收到的／已发送记录 |
| 展示作品供平台用户浏览 | 发布到 Playground | 核对单个结果及生成信息；不等于授予画布编辑权限 |
| 让同事共同操作项目 | 团队项目邀请 | 设置可编辑或仅阅读权限；不等同于分享一个结果 |

**例子：** 将最终咖啡海报分享给审核人即可交付单个结果；需要对方直接修改节点时，再邀请其加入团队项目。准备公开展示时另行发布到 Playground。

铃铛用于查看通知和处理项目邀请。当前消息中心提供通知与内容分享收发记录，**没有私信撰写框**，不要按聊天工具的方式寻找正文发送入口。

详见[消息通知与素材分享](/wiki/collaborate/messages/)、[Playground 作品发布](/wiki/collaborate/playground/)与[权限范围](/wiki/reference/permissions/)。

## 个人设置：密钥可实际参与生成

旧版模型设置只有输入界面；v2 接入个人服务商密钥的保存与调用流程，并提供替换、启用、停用和删除入口。进入头像 → 个人设置／模型设置，按服务商要求填写。

保存成功不等于已经验证上游账号余额、权限或密钥有效性。符合当前模型路由条件的已启用个人密钥会参与调用选择；使用个人密钥提交的任务失败时，不会自动改用系统密钥绕过失败。更换或停用前，应先确认相关任务状态。

**例子：** 你为某服务商配置自己的密钥后，先检查保存状态，再提交确实需要的任务；如果提示余额不足，处理的是相应服务商账号问题，反复更换提示词通常无效。

个人用量面板同时显示使用统计及空间情况。升级后空间数字变化可能来自历史用量补齐，不能仅凭数字增大认定重复生成。详见[登录与个人设置](/wiki/start/account/)。

## 视频：区分两种“草稿”

旧版导航中的“草稿模式”是多轮图像创作页面。当前 v2 已移除这个独立入口，**它与 Seedance 的视频草稿不是同一功能**。

当前 Seedance 2.5 提供 `480p(草稿模式)`：先生成视频草稿，检查运动和构图；符合条件的草稿结果会显示“超分草稿”，选择 1080p 后提交正式视频任务。控制台和画布的相应结果入口都可按状态提供该操作。

- 超分沿用草稿内容，并会另行计费，不是免费下载更清晰的文件。
- 草稿必须可用且未过期，以按钮状态和提示为准。
- 旧版普通 480p 视频不自动成为可超分草稿，其他模型的 480p 也不能按此流程处理。
- 缺少入口时，先核对模型、草稿状态及服务器版本，不要寻找已经移除的旧“草稿模式”页面。

**例子：** 先用草稿检查咖啡杯的环绕镜头；确认满意后再超分。若想改变镜头动作，应先修改描述生成新的草稿，而不是期待超分自动改变内容。

首尾帧和多模态参考并非全部为 v2 新增；不同模型仍有各自输入限制。基础用法见[控制台视频生成](/wiki/create/videos/)。

## 管理员：新增哪些管理入口

| 工作 | v2 的变化 | 使用提醒 |
| --- | --- | --- |
| 模型与服务商 | 新增模型管理，按模型分类查看，并调整服务商排序 | 配置会影响用户可见模型与调用选择，不能以个人前端列表代替平台设置 |
| 视频用量 | 从旧 Seedance 专项统计扩展为视频用量入口 | 核对筛选范围后阅读结果 |
| 用户与容量 | 原有用户管理增加容量设置；用量与存储信息更完整 | 容量保存和其他用户资料修改需分别核对 |
| 存储与恢复 | 增加存储管理、运行详情及相关内容恢复工具 | 恢复范围取决于内容类型，不等于所有已删除文件都能找回 |
| 公共内容 | 管理系统提示词模板、工作流模板及公告 | 工作流保存会影响后续导入；公告需核对受众、时间及发布状态 |
| 排查问题 | 可按用户检索生成错误，结合 Dashboard 与存储运行信息定位 | 优先记录具体错误，不通过反复生成试错 |

![模型管理界面中的模型分类与服务商配置](/media/tutorials/admin-models.jpg)

按模型查看实际服务商配置，再决定是否调整。管理员详细步骤见[用户、模型与用量](/wiki/admin/platform/)和[公共模板与公告](/wiki/admin/content/)。

## 升级后建议先检查这几项

1. **认入口：** 从主导航进入控制台、项目空间、生成资产和 Playground；邀请与分享从铃铛查看。
2. **检查历史：** 查看一条旧生成记录、一个旧项目和一份上传素材，确认能预览和下载。找不到时先检查筛选条件及权限，不要直接删除或重建旧项目。
3. **检查素材与容量：** 历史素材未出现、预览异常或空间数字明显不合理时，向管理员提供内容名称、来源和错误提示。服务器更新代码不等于已经完成历史数据登记与用量补齐。
4. **检查个人配置：** 确认提示词工具和置顶列表开关；如使用个人密钥，核对服务商及启用状态。
5. **再开始协作：** 确认项目是个人还是团队类型，再邀请成员、加入共享素材或发布作品。

**仍然沿用的操作：** 节点复制粘贴创建同类型空节点，不复制原有提示词、参数、结果或连线；画布连线不会自动执行整条流程；平台管理员身份与项目所有者权限也不是同一回事。

若升级后旧素材仍无法查看，请联系部署管理员核对数据库升级、历史素材登记和存储配置。本章是用户功能更新说明，不替代服务器升级操作手册，也不承诺所有旧数据会在拉取代码后自动迁移。
