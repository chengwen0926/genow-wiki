# 项目空间与画布

## 创建项目

**入口：** 项目空间。

1. 选择“个人项目”或“团队项目”页签。
2. 点击新建项目，填写名称，可选上传封面图。
3. 点击创建，进入画布。
4. 首次进入时，可通过引导直接添加图像或视频节点，也可跳过引导。

项目类型取决于新建时所在页签。个人项目适合自己创作；团队项目适合邀请其他账号参与。当前没有将个人项目直接转换为团队项目的常用操作流程，需要协作时应从团队项目开始。

项目卡片菜单提供重命名、更换封面和删除等操作，能否操作取决于所有权。删除项目会影响整张画布，不是仅从自己的列表隐藏。

![新建团队项目填写名称，封面为可选项](/media/tutorials/project-create.jpg)

先确认标题是个人还是团队项目，再填写易识别的名称。图中停在创建前；需要成员协作时从团队项目页签新建。

## 认识画布

- **顶部项目区域：** 查看项目名称及相关项目操作。
- **成员区域：** 查看已加入成员和自己的“所有者／可编辑／仅阅读”状态。
- **左侧工具栏：** 工作流模板、共享素材、参考素材、固定状态、图像节点和视频节点。
- **画布中央：** 摆放节点与连线。
- **节点配置面板：** 编辑提示词、模型、参数和参考内容。
- **小地图：** 帮助定位大画布中的内容。

在画布空白处拖动可调整视野，滚轮或触控板缩放用于观察细节。节点被固定或你处于仅阅读权限时，拖动、连接和编辑能力会受到限制。

左侧“参考素材”用于浏览自己的上传素材；团队画布中的“共享素材”用于浏览当前项目的素材库。二者不是同一可见范围。

## 创建与运行节点

1. 点击左侧“图像节点”或“视频节点”，将节点添加到画布。
2. 选中节点，打开对应配置面板。
3. 选择模型和生成模式，填写提示词。
4. 添加所需参考素材，设置参数。
5. 点击生成，等待节点显示任务结果。
6. 查看节点生成历史，切换并比较已有产物。

图像节点的多图结果可以选择当前显示图；节点下载菜单可下载当前图或全部图片。视频节点用于生成和查看视频。当前画布开放的是图像、视频两种节点，不提供通用文本节点编辑工作区。

普通画布会在操作时保存修改，但保存失败仍需按页面提示处理。离开页面前，先确认上传、生成提交和保存操作已完成。

## 用连线组织上下游参考

从上游节点的连接点拖出连线，连接到下游节点。连接后，进入下游配置面板，检查参考素材区是否出现上游内容，以及当前模型是否接受这种输入。

示例流程：

```text
产品图片节点 → 场景图片节点 → 视频节点
提供产品外形    生成宣传构图    将选定画面变成短视频
```

连线表达输入关系，不会自动运行整条创作流程。先完成上游生成、选择需要的结果，再检查下游参考并手动生成。修改上游之后，已有下游视频不会自动重做。

可以选择一条连线并删除。需要同时移除多条参考关系时，使用下文的 [Ctrl + 右键划动切断多条连线](#ctrl-右键划动切断多条连线)。

**文字步骤：** 找到图片节点右侧的输出端 → 拖到视频节点左侧的输入端 → 打开视频节点，检查首帧和引用标签，再配置并生成。演示仅有两个相关节点；连线本身不会启动生成。

## Ctrl + 右键划动切断多条连线

**适用位置：** 有编辑权限的项目画布。无需先选中连线或节点。

1. 将画布移动或缩放到能看清目标连线的位置，找一段可以连续划过它们的空白区域。
2. **先按住键盘 Ctrl，再按住鼠标右键。Mac 也使用 Control（Ctrl），不是 Command（⌘）。**
3. 保持按住，拖动鼠标，让红色虚线轨迹穿过要删除的连线。一次划动可以穿过多条，按轨迹实际经过的连线判断，不是框选整个区域。
4. **松开鼠标右键后，划过的可删除连线会被移除；最后松开 Ctrl。** 只按住或右键单击不会切断连线，需要有明确的拖动距离。
5. 检查保留的连线，并打开下游节点配置，核对参考素材是否符合新的连接关系，再继续生成。

**例子：** 产品图 A、场景图 B、灯光参考 C 都连到视频节点 D。如果不再需要 A 和 B，让同一次拖动轨迹先后穿过 A→D、B→D，避开 C→D；松开右键后，前两条连线移除，C→D 保留。若希望三条全部移除，可用同一次划动穿过三条。

### 视频：查看切断连线的手势

[Ctrl + 鼠标右键划动：真实画布操作录屏](/media/canvas_mode/切断节点间连线.mp4)

**看视频时注意：** 这段约 6 秒的已有真实录屏逐条展示切断手势，重点是红色轨迹穿过连线、松开后连线消失。它不是“一次划动删除多条”的新录屏；当前版本支持在同一次拖动中穿过多条连线，操作按上面的步骤执行。录屏界面为旧版，节点与工具栏外观可能不同，快捷键与切断动作仍适用。可全屏查看，或通过播放器下方链接下载。

**文字步骤：** 按住 Ctrl → 按住鼠标右键 → 划过目标连线 → 松开右键 → 核对下游参考。

### 取消操作与注意事项

- **尚未松开右键时，按 Esc 可取消本次划动**，再松开鼠标和 Ctrl。松开右键后已提交的切断不能再用 Esc 撤销。
- 这项手势只移除连线，**不会删除两端节点或它们已有的生成结果**；已有下游结果不会自动重新生成。需要恢复参考关系时，重新连接节点并核对输入。
- 松开右键即执行切断，没有额外确认弹窗。连线密集时先放大画布，避开想保留的线。
- 仅阅读成员无法使用；轨迹未穿过连线、拖动距离太短或连线不可删除时，不会移除该连线。
- 如果刷新后连线重新出现，可能是删除没有成功保存；先检查网络与编辑权限，不要仅凭当前画面消失就认定保存成功。

## 涂抹标记

**入口：** 选中有图片结果的图像节点 → 节点工具栏“涂抹标记”。

1. 用画笔、圆形、矩形或箭头标出需要调整的位置；按需切换颜色和粗细，误画时撤销或使用橡皮擦。
2. 点击“保存为新节点”。原图保留，画布新增一张带标记的图片。
3. 新建用于生成的图像节点，将原图和标记图按需要连接到它，检查参考区已出现对应图片。
4. 写清修改要求及标记的含义，例如“以原图为准，将蓝圈内的杯身改为哑光青绿色，保留杯形与光影，去除蓝色标记”。
5. 检查模型、输入与参数，再由你决定是否提交生成。

**保存标记不会调用模型。** 标记属于保存后图片的一部分，不是保证选区外像素不变的蒙版。未在提示词中要求去除时，标记也可能影响生成结果。

![涂抹标记工具用蓝色圆圈标注杯身](/media/tutorials/paint-tools.jpg)

底部选择颜色、工具和粗细；右下角“保存为新节点”只保存标记图。

![原图与新保存的涂抹标记节点并列](/media/tutorials/paint-saved.jpg)

左侧原图没有变化，右侧是独立的标记节点。后续编辑时要明确引用哪一张。

[涂抹标记：保存与连接](/media/tutorials/paint-mark.mp4)

**文字步骤：** 标记杯身 → 保存为新节点 → 将原图和标记图连入生成节点，填写修改与去除标记要求。15 秒静音分步讲解停在提交生成之前。

![原图与标记图连入空白生成节点，配置中填写修改要求](/media/tutorials/paint-connected.jpg)

参考缩略图与连线都核对后，再决定是否生成。图中节点仍为空白，不表示已经生成成功。

## 复制粘贴与删除

选择节点后，Ctrl/Cmd+C、Ctrl/Cmd+V 可快速创建同类型空节点。**当前粘贴不会复制原节点的提示词、参数、结果或连线。** 需要复用完整结构时使用工作流模板。

选择节点后按 Delete，或使用节点上的删除按钮，会请求删除节点及全部生成产物。界面会要求确认。团队编辑者可删除自己创建的节点；项目所有者可以管理项目节点。权限不足或任务仍在使用相关内容时，删除会失败或受阻。

在生成历史列表中，不提供单独删除画布产物的入口。删除前要核对同一节点是否还有需要保留的旧结果。

![左侧原图和右侧复制后创建的同类型空节点](/media/tutorials/canvas-copy-empty.jpg)

复制粘贴后只得到同类型空节点。图中将两个节点分开摆放，便于看清右侧没有原图结果；提示词、参数与连线也不会自动复制。

![节点工具栏展开确认删除和取消操作](/media/tutorials/canvas-delete-confirm.jpg)

点击节点删除按钮后，确认控件出现在节点旁。再次核对节点及全部历史产物；图中停在确认前，可点击“取消”返回。

## 示例 在画布中制作产品视频

新建个人项目“晨光咖啡主视觉”，添加图像节点并生成产品图。选好当前图后添加视频节点，连接两者，检查视频面板中的上游图片。选择支持该参考形式的模式，填写缓慢推进的镜头描述，再提交视频生成。

将两个节点并排放置，可以同时对照产品原图与视频，方便判断视频是否改变了杯柄、杯口或标签等关键细节。
