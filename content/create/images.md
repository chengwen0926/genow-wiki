# 控制台图片生成

## 图片生成的基本流程

控制台输入区负责选择模式、模型、提示词、素材和参数，历史结果区保存任务与产物。每次生成前依次确认：**生成什么、参考什么、用哪个模型、输出什么规格**。

不使用参考图时，模型主要依据文字生成；使用参考图时，可要求保留产品外形、构图或风格。参考图能帮助表达目标，但不能保证所有细节被完全复制。

![图片模型选择器：从当前可用模型中选择适合任务的一项](/media/tutorials/image-model.jpg)

模型入口位于输入框左下角；选择模型后，再检查它支持的参考素材和输出规格。

## 添加与引用参考图

1. 选择支持参考图片的模型。
2. 点击图像素材入口，上传本地图片，或从个人上传历史中选择。
3. 等待上传完成，检查缩略图是否对应正确文件。
4. 在提示词中输入 `@`，通过素材菜单选择图片，插入引用标签。
5. 明确这张图负责什么，例如保留产品形状，或参考场景氛围。
6. 点击生成。

示例中，先通过 `@` 菜单插入产品图标签，再写：

```text
以所选产品参考图中的咖啡杯为主体，保留杯子的形状和颜色。
将背景改为浅米色摄影棚，杯子放在画面中间偏下的位置。
使用柔和侧光，保留自然投影，不增加其他杯子。
```

素材引用应从菜单中选择。仅在普通文字里输入一个文件名，不等于已经把该文件添加为参考。

[参考图：从素材到引用标签](/media/tutorials/reference-guide.mp4)

**文字步骤：** 输入 `@` 打开素材菜单 → 点击示例图片插入 `@图一` → 写清保留外形或参考风格等用途。短片只保留一张咖啡杯示意图，未调用模型生成。

![提示词中的图一引用标签与下方咖啡杯参考图片对应](/media/tutorials/reference-tag.jpg)

检查两处：提示词中有从菜单插入的引用标签，下方有对应的参考图缩略图。

## 参考素材命名与顺序

在素材菜单中，可以通过名称旁的编辑入口修改自己上传素材的显示名称。例如把 `IMG_0021.jpg` 改成“白色咖啡杯正面”，便于在多张素材中识别。

改名不会改写历史生成时保存的名称。历史记录保留当时的素材信息；删除或调整素材顺序后，应重新检查提示词中的引用标签，确保没有缺失引用。

参考素材数量由模型限制。更换模型后，重新检查已有素材是否仍符合新模型要求。

## 常用图片参数

| 参数 | 控制什么 | 使用例子 |
| --- | --- | --- |
| 比例 | 图片的横竖形状 | `1:1` 商品图、`9:16` 竖版宣传、`16:9` 横版展示 |
| 分辨率或尺寸 | 输出像素规格 | 先用可用的较低档验证构图，再按交付要求调整 |
| 张数 | 本次希望获得多少结果 | 一张用于确认方向，多张用于比较构图 |
| 智能比例 | 按该模型和输入规则处理输出比例 | 选择后检查最终结果是否符合交付尺寸 |

比例与分辨率是不同概念：两张图片都可以是 `1:1`，像素尺寸却不同。参数面板没有提供的规格，不能仅靠在提示词里写数字保证实现。

![图片参数面板分别显示画质、比例与生成张数；示例选中2K、1比1和1张](/media/tutorials/image-params.jpg)

示例参数为 `2K · 1:1 · 1张`，用于讲解三个设置的位置，不代表所有模型都提供这些选项。

## 比较结果与迭代

先检查主体数量、外形、背景、光照和裁切，再决定改动。一次只改变一个主要因素，更容易判断是哪项调整影响了结果。

| 操作 | 会带回什么 | 是否直接创建任务 |
| --- | --- | --- |
| 使用提示词 | 仅填入文字，保留当前其他配置 | 否 |
| 重新编辑 | 恢复该记录的模型、参数、参考素材等配置 | 否，需要检查后点击生成 |
| 再次生成 | 使用原生成配置发起新的生成 | 是 |
| 置顶生成信息 | 保存可复用的配置记录 | 否 |
| 收藏 | 标记喜欢的结果，方便查找 | 否 |

“再次生成”会产生新任务，结果可能与上一张不同。不要用它处理单纯的缩略图加载失败。

## 置顶常用生成配置

**入口：** 历史记录操作区 → 置顶生成信息；控制台左侧边缘 → 置顶。

1. 在个人设置中开启置顶列表。
2. 找到一条值得复用的生成记录，点击置顶操作。
3. 打开左侧置顶面板，查看提示词、模型、参数和参考素材。
4. 点击“添加到控制台”，恢复整套配置。
5. 检查参考素材和模型是否仍可用，再点击生成。
6. 不再需要时，点击“取消置顶”。

同一条历史记录重复置顶不会产生多个副本。取消置顶不会删除生成结果。

置顶保存的是配置，不能当作素材备份。原件删除或主体资源失效后，即使置顶仍在，也可能需要重新选择参考素材。当前控制台以历史记录置顶为主要入口，没有独立的“保存尚未生成的当前配置”按钮。

## 示例 制作两种尺寸的产品图

先按[生成第一张图片](/wiki/start/first-image/)生成一张方形图；选中满意记录，点击“重新编辑”，保留产品描述，将比例切为 `9:16`，并增加“主体位于下半部，上方留出干净背景”。生成后比较主体是否完整。

此流程会重新创作一张竖图，并不是把原图无损改尺寸。如果产品外形需要保持一致，应同时使用产品参考图。
