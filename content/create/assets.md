# 生成资产与个人素材

## 三种内容分别在哪里

| 内容 | 从哪里找 | 保存的重点 |
| --- | --- | --- |
| 控制台生成历史 | 控制台结果区 | 当次提示词、参数、状态和产物 |
| 生成资产 | 导航“生成资产” | 可预览、收藏、下载的结果文件 |
| 个人上传素材 | 输入区的素材菜单或画布“参考素材” | 自己上传并准备反复引用的图片、视频和音频 |

生成的图片不会因为出现在历史里，就自动等同于个人上传素材。需要再次作为参考时，通过界面提供的选择或添加入口处理。

## 查找与收藏生成结果

1. 打开“生成资产”。
2. 选择来源：控制台、个人画布或团队画布。
3. 选择媒体类型：图像、视频，或两者。
4. 如只找收藏内容，打开收藏筛选。
5. 按日期浏览，点击结果进入详情。

来源与类型支持组合选择。**某一组全部取消时，会显示空列表，并不表示全部选中。** 找不到结果时，先确认这两组筛选至少各选择一项。

点击收藏星标即可标记结果，再次点击可取消。收藏方便查找，但不会创建文件副本，也不阻止源内容删除。

## 预览与下载

详情中可查看图片、播放视频，并阅读可访问的提示词、模型、参数和参考信息。视频还可截取当前帧，具体见[控制台视频生成](/wiki/create/videos/)。

需要批量下载时：

1. 在生成资产页进入批量下载选择模式。
2. 逐个选择结果，或使用页面的框选交互选择多个。
3. 确认选中内容后执行下载。
4. 等待浏览器获得压缩包，再解压检查文件。
5. 完成后退出选择模式。

下载失败时先检查是否仍有访问权限、媒体能否正常打开，以及浏览器是否拦截下载。不要以重新生成来代替下载重试。

## 管理个人上传素材

通过输入区的图像、视频、音频素材菜单，可以选择已有上传内容，或继续上传新的文件。可按入口提供的名称编辑按钮修改显示名称。

对不常用的个人上传素材，可使用“移除素材”将其从素材库隐藏。移除处理的是库条目，保留已有引用，不会改写过去的生成记录。

当前常用素材选择界面没有接入“已移除的素材”恢复入口。误移除后需要再次选择时，可联系管理员协助核对和恢复条目，或重新上传仍持有的原文件。素材库条目恢复也不是生成资产删除后的回收站。

## 删除前区分操作对象

| 操作位置 | 实际影响 | 能否通过普通界面恢复 |
| --- | --- | --- |
| 当前输入区移除参考项 | 不再用于本次输入 | 可重新选择仍可用的素材 |
| 个人上传素材库移除 | 从个人库隐藏条目，保留已有引用 | 当前网页无恢复入口，联系管理员协助 |
| 项目共享素材库移除 | 解除该项目素材条目，不等于删除原始文件 | 有权限且源素材可用时，可重新加入 |
| 生成资产删除 | 删除所选生成产物；原件不能再正常下载或用于新生成 | 没有用户回收站恢复入口 |
| 控制台历史删除 | 按该条记录涉及的生成产物处理 | 没有用户回收站恢复入口 |
| 画布节点删除 | 删除节点及其全部生成产物 | 确认后不能在界面中撤销 |
| 项目删除 | 进入整个项目的删除处理 | 不是可撤销的归档操作 |

已被后续任务使用的素材，可能保留必要的历史预览，用于解释当时的输入。看到“已删除的历史参考素材”不代表原件仍可下载或再次生成。需要复现时，应重新上传或选择有效素材。

## 批量删除与删除受阻

在生成资产页进入批量删除模式，选择控制台产物，核对数量后确认。画布产物需要前往所属画布删除节点，不能在资产页单独删掉其中一张。

批量删除可能部分成功。已成功删除的内容会从列表移除，受阻内容保留，并显示原因：

- “正在被生成任务使用”：等相关任务结束后再操作。
- “请前往画布删除所属节点”：改到画布处理，不反复在资产页点击。
- “历史参考预览尚未准备完成”：稍后重试，持续出现时联系管理员。
- “存储资料尚待核对”或“历史引用尚待核对”：记录错误并联系管理员。

不要将尚未收到成功结果的删除请求视为已经完成。删除生成产物也可能影响对应的作品发布和内容分享，应先下载确实需要保留的成果。

## 示例 整理咖啡产品图

选择“控制台”和“图像”，找到本次生成日期，给三张满意结果加星标。打开收藏筛选，批量下载这三张。最后退出下载模式，再单独选择不需要的失败构图删除，避免在交付选区中误删成品。
