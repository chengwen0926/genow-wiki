# 控制台视频生成

## 按输入条件选择模式

**入口：** 控制台 → 视频生成 → 模型与模式选择。

| 模式 | 主要输入 | 适合的任务 |
| --- | --- | --- |
| 文生视频 | 文字描述 | 先探索场景、动作与镜头 |
| 图生视频或首帧生成 | 起始图片与动作描述 | 让已有产品图产生运动 |
| 首尾帧 | 开始图片、结束图片及过程描述；是否两张都必填以模型为准 | 控制场景的起点和终点 |
| 智能参考或多图参考 | 模型允许的图片、视频、音频或主体 | 组合人物、物体、场景与动作参考 |
| 视频编辑 | 输入视频与修改要求 | 在支持的模型中改变视频内容 |
| 视频延长 | 输入视频及后续动作描述 | 在支持的模型中继续已有片段 |

以上是平台中不同模型的能力集合，不代表每个模型都支持全部模式。先选模型，再查看该模型实际显示的模式。

![视频参数面板：先选首尾帧或智能参考，再设置比例、分辨率和生成时长](/media/tutorials/video-params.jpg)

示例选择 Seedance 2.0 的首尾帧模式；不同模型提供的模式和参数不同，先选模型，再检查可用选项。

## 从图片生成视频

1. 选择支持图生视频的模型和模式。
2. 在首帧位置添加产品图，等待素材就绪。
3. 填写主体动作和镜头运动，避免只重复描述静态图片。
4. 选择模型支持的时长、比例与分辨率。
5. 检查是否还有必填素材，点击生成。
6. 结果完成后播放整个视频，检查主体变形、运动连续性和结束画面。

```text
镜头缓慢向咖啡杯推进，杯口热气轻轻向上飘动。
杯子始终放在桌面上，保持杯子的形状、颜色和位置稳定。
背景维持柔和虚化，光线平稳，不切换场景，不增加文字。
```

如果模型允许 5 秒，可以先制作 5 秒版本；否则选择界面允许的相近时长，不强行输入不支持的值。

[视频生成：首帧模式设置](/media/tutorials/video-setup.mp4)

**文字步骤：** 在参数面板确认模式与规格 → 放入首帧并检查缩略图 → 描述镜头运动和主体动作，检查后提交。短片不展示模型生成过程；画面中的咖啡杯是专用示意素材。

## 首尾帧与多种参考素材

首帧决定开始画面的参考，尾帧决定结束画面的参考。上传前确认两张图片的位置，不要把尾帧误放在首帧槽位。

示例：首帧为咖啡杯远景，尾帧为同一杯子的近景。提示词可以写“镜头连续缓慢推进，从桌面全景过渡到杯口特写，保持杯子外观一致”。两张图主体差异过大时，过渡更容易出现不自然变化。

智能参考模式下，通过 `@` 菜单选择素材，并写清各自用途。例如“参考图一中的产品外形，参考视频一中的镜头节奏”。音频只在模型支持的模式下用作参考；平台没有通用的独立音频生成工作区。

## 视频参数与模型专属选项

| 参数 | 说明 | 操作提醒 |
| --- | --- | --- |
| 时长 | 希望生成的片段长度 | 某些模型固定时长，不能任意修改 |
| 智能时长 | 由支持该能力的模型决定长度 | 开启后不能手动调整时长 |
| 比例 | 视频横竖方向 | 竖屏宣传常用 `9:16`，横屏展示常用 `16:9` |
| 分辨率 | 视频清晰度规格 | 必须使用当前模式允许的值 |
| 多镜头 | 允许支持该能力的模型生成多镜头内容 | 需要连续单镜头时，可先关闭此选项 |
| 档位 | 模型提供的不同运行档位 | 按界面选项选择，不能假设档位在各模型间等价 |

切换模型或模式后，应重新检查参数、参考数量和首尾帧槽位。上一个模型可用的组合可能不适用于当前模型。

## Vidu 主体与 Kling 元素

主体资源用于重复引用同一个人物或物体。使用前先选择支持主体的模型及模式，打开“主体”入口。

**Vidu 主体：** 选择已有主体，或进入创建界面，填写主体名称，上传 1～3 张图像，再点击“创建并选择”。示例名称为“白色咖啡杯”，图片使用正面、侧面和俯视图。

**Kling 元素：** 填写主体名称和外观描述，上传必填封面图，可再添加最多 3 张视角图，点击“创建并选择”。等待创建完成后再用于生成。

主体创建中、失败或结果待核实时，不能将其视为可用资源。Kling 删除请求若显示“处理中”或“待核实”，当前不会通过刷新自动确认远端删除成功；应联系管理员核实，不连续重复提交删除。

主体资源与服务商账号有关，不能等同于普通项目素材直接跨账号共享。团队可以共享原始图片，再由需要使用的成员在自己的可用凭据下建立主体。

## 下载视频与截取画面

点击视频进入详情，播放到目标画面后，可使用“截取当前帧”。确认预览后选择：

- **下载到本地：** 保存该帧图片。
- **添加到图像素材：** 保存到个人图像素材库，便于后续选择。

截帧加入素材库不会自动替换当前任务的参考图。需要再次使用时，返回生成输入区，主动从图像素材中选择。
